# Тихая смена — первая итерация

Вертикальный срез на **Godot 4** (проверено на 4.6.3, открывается с 4.3).
Одна сцена, `res://scenes/main.tscn`, в ней видно ядро действия, камеру,
стиль и палитру. Арт — плейсхолдеры, но в заданном свете и цвете.

Ремонтник по контракту 4417-Б работает на заброшенной узловой станции
«Тишина-9». Задача смены: собрать узлы из лома, поднять энергосеть и
удержать канал ретранслятора 90 секунд.

## Как запустить

```bash
godot --path quiet-shift
```

Или: Godot → Import → выбрать папку `quiet-shift` → Run (F5).
Ассетов-файлов нет вообще: мир, тела, звук и интерфейс собираются кодом,
поэтому проект не тянет за собой бинарники и открывается сразу.

## Управление (клавиатура и мышь)

| | |
|---|---|
| WASD | идти, мышь — камера от третьего лица |
| SHIFT | быстрее |
| ПРОБЕЛ | стабилизатор (короткая тяга, заряд восстанавливается у работающих узлов) |
| ЛКМ / F | взять или положить деталь |
| E | установить деталь в узел, заправить генератор, загрузить переработчик |
| 1…6 | тумблеры узлов сети |
| TAB | масштаб обзорного экрана, M — звук, ESC — отпустить курсор |

## Ядро действия за три минуты

1. Вокруг площадки лежат годные детали (пластины, катушки, ячейки) и лом.
   Всё это физические тела: их несут в руках, они качаются, стучат по
   корпусам и скатываются по склонам.
2. Гнёзда узлов подсвечены. Принеси **пластину** и **катушку** в ГЕН-4 —
   генератор собран. Вставь **ячейку** — он даёт до 14 кВт.
3. Собери БНК-1 (батарея сглаживает пики), П-2 (переработчик делает детали
   из лома, но ест 3 кВт), маяки М-1…М-3 (по 2 кВт, освещают туман) и
   РТР-9 (8 кВт, цель смены).
4. Полный спрос — 17 кВт при выдаче 14. Сеть считается непрерывно, поэтому
   смена превращается в реальный выбор: что держать включённым сейчас.
   Дефицит — не проигрыш, а просадка: свет тускнеет, переработчик
   замедляется, канал не держится. Выключил лишнее — всё вернулось.
5. Продержи канал 90 секунд — наряд закрыт. Смена на этом не кончается.

Проверено сквозным прогоном: прицел → перенос → установка → выдача
мощности → выдача деталей переработчиком → просадка при перегрузе →
закрытие наряда.

## Что где лежит

| Файл | О чём |
|---|---|
| `scripts/game.gd` | сборка сцены, свет и воздух, ввод, цель смены, ироничный голос журнала |
| `scripts/world_builder.gd` | рельеф, камни, станция, завалы — всё по фиксированному зерну |
| `scripts/power_net.gd` | сеть в реальном времени: выдача, спрос, батарея, просадка |
| `scripts/machine.gd` | узел: гнёзда, топливо, заряд, цикл переработки |
| `scripts/player.gd` | тело ремонтника на силовых регуляторах |
| `scripts/camera_rig.gd` | камера через плечо, свой луч против перекрытий |
| `scripts/hud.gd` | плотный интерфейс целиком в одном `_draw` |
| `scripts/palette.gd` | **единственный источник цвета** во всём проекте |
| `scripts/sound_desk.gd` | электронный гул и сигналы, синтез на месте, без файлов |
| `tools/demo/` | автопилот для записи демо: сцена `demo.tscn` и сценарий `demo_autopilot.gd` |

Крутить баланс: константы в `machine.gd` / `world_builder.gd`
(14 кВт выдачи, 2 кВт на маяк, 8 кВт на канал, 6 с на цикл переработки),
цель смены — `uplink_goal` в `game.gd`, свет и туман — `_build_sky()`.

## Запись демо

Автопилот проходит игровой цикл штатными действиями ввода — идёт, целится,
берёт, ставит, щёлкает тумблерами, — а встроенный Movie Maker Godot пишет
кадры и звук. Запись занимает ~25 секунд и сама завершается.

```bash
godot --path . res://tools/demo/demo.tscn --write-movie demo.avi --fixed-fps 30
```

AVI получается тяжёлым (~100 МБ); сжать в MP4:

```bash
ffmpeg -i demo.avi -vf scale=1280:-2 -c:v libx264 -crf 23 -pix_fmt yuv420p -c:a aac demo.mp4
```

Сценарий — массив `PLAN` в `tools/demo/demo_autopilot.gd`, шаги и их
параметры описаны в шапке файла. Шаг `fill` закрывает оставшиеся гнёзда без
переноски: он нужен, чтобы быстро показать сеть под полной нагрузкой, а не
для проверки рук. Готовая запись лежит в `shots/demo.mp4`.

## Решения по реализации, которые стоит знать

* **Анимации нет вообще.** Поза тела каждый кадр — результат сил: торс висит
  на пружинном регуляторе высоты бедра и держится прямо моментом, ступни —
  отдельные тела, которые ПД-регулятор ведёт по фазе шага (поэтому они
  задевают камни), руки и голова — тела, тянущиеся к своим целям, как моторы
  активной ragdoll-модели. Колени рисуются двухзвенной ИК по фактическому
  положению ступни.
* **Шарниры (`PinJoint3D`) сознательно не используются.** В Godot Physics они
  при рабочем `damping` гасят качание почти до нуля, а при малом — расходятся
  в NaN. Силовые регуляторы дают то же качание и остаются устойчивыми.
* Коэффициенты моментов рассчитаны по моменту инерции тел, а не по массе:
  на лёгких деталях «моменты по массе» разлетаются за несколько кадров.
* Коллайдер рельефа двусторонний: односторонний trimesh в Godot ловит
  столкновения только с обратной стороны, и герой падал сквозь грунт.
* Ввод регистрируется кодом (`game.gd::_setup_input`), чтобы проект
  открывался в любой сборке 4.x без правки InputMap.

## Соответствие заданию

| Ось | Как сделано |
|---|---|
| ресурсы, реальное время | сеть, топливо, лом и детали считаются непрерывно; решения принимаются на ходу |
| прощающая неудача | смерти нет, потерь нет; дефицит — просадка, из которой всегда есть выход |
| открытый мир | участок 220×220 генерируется процедурно по зерну; станция — первый узел, а не коридор |
| часы за заход, длинная игра | цикл «лом → детали → мощность → новые узлы» расширяется добавлением узлов и участков |
| фантастика, деловой тон, ироничный голос | служебные формулировки в журнале, в которых проговаривается то, о чём отчёты молчат |
| заданный протагонист-профессионал | сертифицированный ремонтник по наряду; сюжет — фон, работа — передний план |
| 3D, третье лицо, открытое пространство | камера через плечо со своим лучом против перекрытий |
| нуар, приглушённая палитра, туман | один тёплый акцент (амбер) на холодном сером; объёмный туман; свет есть только там, где есть мощность |
| детализированная подача | силуэты, плиты, мачты, тарелка, силуэт разбитого корабля на горизонте — плейсхолдеры, но собранные в кадр |
| физика вместо скелетной анимации | см. выше |
| плотный интерфейс | сеть, баланс, груз, цель, журнал и обзорный экран видны одновременно |
| электроника | синтез на месте: гул станции, шум, служебные сигналы |
| клавиатура и мышь | только они |

## Что дальше (не входило в первую итерацию)

* Больше типов узлов и деталей; рецепты переработки вместо круговой выдачи.
* Второй участок и переход между участками (генератор мира уже параметрический).
* Модели вместо плейсхолдеров; палитра и свет менять при этом не нужно.
* Сохранение смены; сейчас состояние живёт только до выхода.
